# Разрешение на использование голоса Irina (RHVoice) в audioreferent

**Что используется.** Голос синтеза речи Piper `ru_RU-irina-medium`
(rhasspy/piper-voices v1.0.0), обученный на записях голоса Irina проекта
RHVoice. По документу RHVoice (`doc/en/License.md`) голоса лаборатории
распространяются под CC BY-NC-ND 4.0; для включения голоса в продукт
предусмотрен запрос в лабораторию и её разрешение.

**Запрос.** 12.09.2026 правообладатель продукта (Пономарев Роман Сергеевич,
romprs@gmail.com) направил письмо на rhvoice@rhvoice.org (копия
rhvoice@tiflo.org) с темой «Запрос разрешения на использование голоса Irina
в программном продукте»: описан продукт (офлайн-помощник для РЕД ОС),
характер использования (только озвучивание ответов внутри программы,
локально, без извлечения и отдельного распространения голоса, без обучения
других моделей, с указанием авторства RHVoice и диктора), коммерческое
распространение организациям.

**Ответ.** 12.09.2026, 22:25 (по времени получателя), от Артема Плаксина,
руководителя лаборатории Tiflo RHVoice (rhvoice@tiflo.org, тел.
+7 (952) 280-89-89), в ответ на запрос:

> Для Ирины не требуется дополнительное разрешение.

**Как оформить для пакета документов.**

1. Сохранить оригинал переписки (запрос и ответ) из почтового ящика
   romprs@gmail.com в формате `.eml` (Gmail: «Показать оригинал» →
   «Скачать оригинал») и в PDF — положить рядом с этим файлом как
   `RHVoice_Irina_permission.eml` и `RHVoice_Irina_permission.pdf`.
   Эти файлы в git не хранятся (личная переписка); в пакете документов —
   обязательны.
2. В перечне сторонних компонентов (`THIRD_PARTY.md`, документ 05
   пакета) для голоса `ru_RU-irina-medium` ссылаться на это подтверждение.
3. В документации продукта (руководство пользователя, «О программе»)
   указывать авторство: «Голос Irina — проект RHVoice (rhvoice.org),
   лаборатория Tiflo RHVoice; синтез речи — Piper (rhasspy/piper)».

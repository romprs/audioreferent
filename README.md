# audioreferent

Голосовой помощник для РЭД ОС: команды на русском языке, активация по
настраиваемому ключевому слову (по умолчанию — «Вика»).

## Архитектура

- **Распознавание речи** — [Vosk](https://alphacephei.com/vosk/) (офлайн, без
  отправки аудио куда-либо). Небольшая модель работает постоянно в фоне.
- **Активация по ключевому слову** — не отдельная акустическая wake-word
  модель, а нечёткое сравнение (расстояние Левенштейна) распознанного текста
  с настроенным словом. Это позволяет менять слово в конфиге без
  переобучения чего-либо.
- **Команды** — фиксированный список фраз → действие, задаётся в конфиге.
  Никакого общего NLU: для ограниченного набора команд точное/подстрочное
  сопоставление надёжнее.
- **Действия** — выполняются универсальными для Linux средствами (XDG,
  `systemd-logind`, `pactl`/`amixer`), без привязки к конкретному DE
  (MATE, KDE и т.д.).

## Установка на RED OS

**Через RPM** (`packaging/audioreferent.spec`, см. `packaging/README.md`) —
рекомендуемый способ для закрытого контура без интернета: пакет
самодостаточен, полная модель Vosk (без `rescore`/`rnnlm` — см. ниже,
почему) и модель проверки голоса уже внутри (`/usr/share/audioreferent/`),
отдельно скачивать ничего не нужно:

```bash
sudo dnf install ./audioreferent-<версия>.rpm
```

**Через pip** (для разработки/там, где есть интернет):

```bash
sudo dnf install python3-pip python3-devel portaudio-devel alsa-lib-devel espeak-ng xdotool python3-pyside6 mpg123
python3 -m pip install --user .

# Модель распознавания речи (пример — маленькая русская модель)
mkdir -p ~/.local/share/vosk
curl -L -o /tmp/model.zip https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
unzip /tmp/model.zip -d ~/.local/share/vosk
export VOSK_MODEL_PATH=~/.local/share/vosk/vosk-model-small-ru-0.22
```

`VOSK_MODEL_PATH` стоит прописать в `~/.bash_profile` или в systemd-юните
(`Environment=`), либо указать `model_path` прямо в конфиге (через
`audioreferent settings` или руками в `config.yaml`).

### Более точная модель (при проблемах с распознаванием в шуме)

Маленькая модель (`vosk-model-small-ru-0.22`, ~45 МБ) урезана под
встраиваемые системы ценой точности. При постоянных ложных
срабатываниях/пропусках команд стоит попробовать полную модель
(`vosk-model-ru-0.42`, ~1.9 ГБ, ~1.1 ГБ RAM в работе) — тот же API, тот
же стриминг, просто замена `model_path`, без изменений кода:

```bash
curl -L -o /tmp/model.zip https://alphacephei.com/vosk/models/vosk-model-ru-0.42.zip
unzip /tmp/model.zip -d ~/.local/share/vosk
```

**Известная проблема**: у этой модели опциональные каталоги `rescore/`
(перескоринг более мощной LM) и `rnnlm/` (перескоринг RNN-LM) не грузятся
с версией `vosk` из PyPI на момент проверки (0.3.45) — `rescore/G.carpa`
даёт ошибку чтения, `rnnlm/` роняет процесс сегфолтом уже при простой
загрузке модели. Решение — убрать оба каталога, останется базовый граф
(`HCLG.fst`) без этих надстроек, но это всё равно значительно точнее
маленькой модели:

```bash
rm -rf ~/.local/share/vosk/vosk-model-ru-0.42/rescore
rm -rf ~/.local/share/vosk/vosk-model-ru-0.42/rnnlm
```

## Настройка

Пользовательский конфиг: `~/.config/audioreferent/config.yaml` (переопределяет
отдельные ключи поверх встроенных значений по умолчанию — см.
`src/audioreferent/default_config.yaml`).

```bash
audioreferent set-wakeword "Вика"
audioreferent list-devices
```

Либо через GUI-окно настроек (активационное слово, порог нечёткости
слова, микрофон, время ожидания команды, звук/голос, список команд) —
`python3-pyside6` нужен только для этого окна, сам помощник без него
работает:

```bash
audioreferent settings
```

Устанавливается и как обычное приложение в меню (`packaging/audioreferent-settings.desktop`
при установке через RPM).

## Запуск

```bash
audioreferent run
```

Как systemd user-сервис (при установке через RPM юнит уже стоит в
`/usr/lib/systemd/user/` — достаточно `systemctl --user enable --now
audioreferent.service`; ниже — для установки через `pip install --user`):

```bash
mkdir -p ~/.config/systemd/user
cp systemd/audioreferent.service ~/.config/systemd/user/
# ExecStart в файле указывает на /usr/bin/audioreferent (путь RPM) —
# для pip install --user поправьте на %h/.local/bin/audioreferent
sed -i "s|/usr/bin/audioreferent|%h/.local/bin/audioreferent|" ~/.config/systemd/user/audioreferent.service
systemctl --user daemon-reload
systemctl --user enable --now audioreferent.service
```

## Проверка без микрофона

```bash
audioreferent test-command "открой браузер" --dry-run
```

| «сделай тише» / «уменьши громкость» / «тише» | −10% громкости |
| «выключи звук» / «заглуши звук» / «без звука» | выключить звук |
| «включи звук» | включить звук |
| «заблокируй экран» / «заблокируй компьютер» | заблокировать сеанс |
| «найди …» / «найди в интернете …» / «поищи …» | поиск в браузере по тому, что сказано после фразы |
| «запусти яндекс браузер» / «открой яндекс браузер» | запуск Яндекс Браузера |
| «открой сайт …» / «перейди на сайт …» | открыть сайт: алиас из конфига (`args.sites`), либо буквальный адрес («точка» → «.»), иначе — обычный поиск по сказанному |
| «сверни текущее окно» / «сверни окно» | свернуть активное окно (нужен `xdotool`) |
| «закрой текущее окно» / «закрой окно» | закрыть активное окно штатным запросом (нужен `xdotool`) |
| «сверни все окна» | свернуть все окна, кроме панели/рабочего стола (нужны `xdotool`/`wmctrl`) |
| «сохрани документ» / «сохрани файл» | отправить Ctrl+S активному окну (нужен `xdotool`) |
| «создай текстовый документ» | новый документ в Р7-Офис (`r7-office-desktopeditors --new:word`) |
| «создай табличный документ» / «создай таблицу» | новая таблица в Р7-Офис (`--new:cell`) |

Новые команды добавляются в секцию `commands` конфига без изменения кода.
Действие `search_web` использует остаток фразы после команды как поисковый
запрос (см. пример в `default_config.yaml`); URL поисковика можно
переопределить через `args: {engine_url: "https://ya.ru/search/?text={query}"}`.

## Управление почтовым клиентом redmail

Если на этой же машине запущен [redmail](https://github.com/romprs/redmail),
голосовые команды могут им управлять через его локальный канал IPC
(`redmail_client.py` читает адрес сокета из
`~/.config/redmail/ipc-endpoint.json`, публикует его сам redmail при
запуске). Если redmail не запущен, команда так и скажет — «Почта не
запущена».

| Фраза | Действие |
|---|---|
| «открой почту» / «запусти почту» | вывести окно redmail на передний план (не запущен — запустить) |
| «создай встречу [<тема>] [<дата>] [<время>]» | открыть в redmail окно новой встречи и перейти в режим заполнения (ниже) |
| «измени встречу <тема> [<дата>]» | найти свою встречу по теме/дню и открыть её окно в режиме заполнения |
| «перенеси встречу <тема> [<старая дата>] [<старое время>] на <новая дата> <новое время>» | найти встречу по теме/дню и открыть её перенос с новым временем |
| «отмени встречу <тема> [<дата>]» | найти встречу по теме/дню и открыть её отмену |

### Режим заполнения встречи

После «создай встречу» / «измени встречу» окно встречи redmail открыто, и
помощник слушает поля **без активационного слова** (оно допускается, но не
нужно), пока окно открыто. Каждая фраза — одно поле, изменение сразу видно
в окне:

| Фраза | Поле |
|---|---|
| «тема планёрка» | название |
| «дата пятнадцатое сентября» / «дата следующий понедельник» / «дата завтра» | дата (год — всегда текущий) |
| «время восемь тридцать» | время начала (конец сдвигается, длительность сохраняется) |
| «продолжительность два часа» / «полтора часа» / «сорок минут» | длительность |
| «повторение каждую неделю» / «каждый день» / «каждый месяц» / «нет» | повторение |
| «участники шилкин пономарёв будько» / «пригласить шилкина» | участники — по фамилии из адресной книги redmail (падеж не важен) |
| «место кабинет сто двадцать один» | место |
| «описание утренняя планёрка» | описание |
| «сохранить» | нажать «Сохранить» — с этого момента, как и от кнопки, уходят приглашения |
| «отменить» | нажать «Отмена» |

Ответы звучат только при ошибке или завершении: «Не поняла
дату/время/продолжительность/повторение», «Участник не найден» (фамилия не
нашлась или нашлось несколько — кто именно, в журнале), «Нельзя
запланировать встречу на прошедшую дату», «Встреча сохранена», «Отменено».
Принятое поле подтверждается коротким сигналом. Фразы не про форму
игнорируются; `form_timeout_seconds` (по умолчанию 60) тишины — режим
выключается, окно остаётся открытым. На время проигрывания ответа
микрофон сбрасывается — помощник не слушает собственное эхо.

## Голосовой ответ (синтез речи)

Ответы озвучивает **Piper TTS** (`tts.py`): офлайн, ~0,1 с на фразу, любой
текст одним голосом. Программа `piper` (сборка rhasspy/piper 2023.11.14,
MIT) и голоса лежат в `/opt/audioreferent/piper/` и
`/usr/share/audioreferent/piper/` (ставятся RPM) либо в
`~/.local/share/audioreferent/piper/`. Голос выбирается в настройках
(`piper_voice`): по умолчанию `ru_RU-irina-medium` — женский, голос RHVoice
(лаборатория Tiflo RHVoice подтвердила 12.09.2026, что дополнительного
разрешения не требуется, см. `docs/licenses/`); `ru_RU-denis-medium`,
`ru_RU-dmitri-medium` — мужские, CC0. Проверить из терминала:

```bash
audioreferent say "Встреча сохранена" --voice ru_RU-irina-medium
```

Если программы или голоса нет (`tts_engine: recordings` либо файлы не
найдены), помощник отвечает заранее записанными фразами `voice/*.mp3`, а для
текста без записи — общим «Не удалось выполнить команду»; espeak-ng — последний
резерв. При старте сервиса фиксированные фразы синтезируются заранее.

**Важно про подтверждение**: ни одна из этих команд не отправляет ничего
сама — они лишь просят redmail открыть его обычный диалог (новая/изменённая/
отменённая встреча) с уже заполненными по голосу полями. «Сохранить» /
«Да, отменить» всё равно нажимает человек — эта гарантия сделана на стороне
redmail (`ipc_server.py`) и не может быть обойдена никакими аргументами
голосовой команды.

Дата не названа — по умолчанию берётся сегодняшняя (кроме «новой» даты в
переносе — та обязательна вместе с новым временем, где-то на неё нужно
перенести). Даты понимаются в двух видах: относительные
(«сегодня»/«завтра»/«послезавтра») и абсолютные — «10 сентября» цифрой или
«десятое сентября»/«двадцать пятое сентября» словами, без года (берётся
текущий год, либо следующий, если такая дата в этом году уже прошла).
Время — «в 15 часов 30 минут», «в пятнадцать тридцать» или просто «в
пятнадцать» (значит 15:00); «полдень»/«полночь» тоже понимаются. Разбор —
`ru_datetime.py`, без общего NLU, только эта одна грамматика.

Перенос и отмена ищут встречу через `find_events` (тема — подстрока,
регистронезависимо; день) — если по теме и дню нашлось больше одной
встречи, команда пробует сузить по названному старому времени, а если и
это не помогло — просит уточнить тему голосом, а не переносит/отменяет
наугад.

## Голосовая биометрия (проверка «чей это голос»)

Опциональный фильтр: выполнять команды только от голоса, для которого
записан образец, игнорируя остальные (посторонние люди, фоновый
телевизор). Это **не** средство от плохого распознавания в шуме —
раздельная задача, решается моделью/порогом нечёткости слова (см. выше).

Настраивается на вкладке «Голосовая биометрия» в `audioreferent settings`:
запишите 1-3 образца (кнопка «Записать образец голоса», 5 секунд), включите
«Проверку голоса» и подберите порог схожести. Пока образцов нет или галочка
выключена — работает как раньше, эта функция полностью опциональна.

Использует отдельную модель Vosk `vosk-model-spk-0.4` (~14 МБ, x-vector,
не заменяет основную модель распознавания речи):

```bash
curl -L -o /tmp/spk.zip https://alphacephei.com/vosk/models/vosk-model-spk-0.4.zip
unzip /tmp/spk.zip -d ~/.local/share/vosk
```

## Известные ограничения MVP

- Не включены необратимые действия (выключение/перезагрузка компьютера) —
  риск случайного срабатывания при ошибке распознавания.
- Голосовой ответ (`feedback.speech`) для двух стандартных фраз («Команда
  не распознана», «Голос не соответствует эталону») использует заранее
  записанные mp3 (`src/audioreferent/voice/`, женский голос, сгенерирован
  офлайн один раз через внешний TTS-сервис — играются через `mpg123`, не
  синтезируются в рантайме). Любая другая фраза (например, кастомная в
  `feedback.speak(...)`) по-прежнему идёт через `espeak-ng` — качество
  синтеза там базовое; чтобы добавить запись для новой фразы, нужно
  сгенерировать mp3 и прописать её в `_PRERECORDED_PHRASES` в
  `feedback.py`.
- Упаковка в RPM для дистрибуции по РЭД ОС не реализована — установка через
  `pip install --user`.
- Команды сворачивания окон/Ctrl+S используют `xdotool`/`wmctrl` — это
  требует X11 (Wayland не поддерживается) и опирается на заголовки окон
  для исключения панели/рабочего стола из «сверни все окна» (настраивается
  через `args.exclude_titles` под другое DE). Команды создания документов
  жёстко привязаны к Р7-Офис (`r7-office-desktopeditors`), в отличие от
  остальных действий — это осознанное исключение из принципа
  DE-независимости, так как Р7-Офис — часть стандартной поставки РЭД ОС.
- «Открой сайт …» распознаёт адрес по слуху ненадёжно: работает точно
  через алиасы в конфиге или явное «точка», в остальных случаях подстраховкой
  служит обычный поиск по сказанному.
